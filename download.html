Requirements

Before you install

LXX requires Python 3.8–3.13 installed from python.org. The Microsoft Store version of Python will not work.

⬇ Python 3.13 (Recommended) ⬇ Python 3.11 (Stable)
⚠️ Check "Add Python to PATH" on the first screen of the Python installer — otherwise Windows won't find Python when you run the scripts.
Setup

Installation steps

1

Download and extract the zip

Click the Download button above. Right-click the .zip → Extract All → choose a folder like C:\LXX\.

2

Run setup (installs dependencies)

Double-click setup.bat inside the extracted folder. It automatically runs:

pip install customtkinter keyboard pyperclip
3

Launch LXX

Double-click run.bat, or open a terminal in the folder and run:

python main.py
4

Link your account (optional)

Create an account, copy your Auth Token from the Dashboard, and click Link Account in the LXX overlay. This unlocks Premium if you have it.

⌨️ Hotkeys

Ctrl + Space Transform & replace what you just typed
Ctrl + Shift + Space Toggle overlay visible / hidden
Ctrl + Shift + X Toggle keyboard interceptor on / off

🔧 Troubleshooting

"python is not recognized" — Re-run the Python installer and check "Add Python to PATH".
Keyboard hook fails — Right-click run.bat → Run as Administrator.
Black screen / no window — Make sure you extracted the .zip fully before running.
