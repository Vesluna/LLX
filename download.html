Requirements

Before you install

You need Python 3.8–3.13 from python.org.
⚠️ Python 3.14 is NOT yet supported — pygame wheels aren't available for it.

⬇ Python 3.13 (Recommended) ⬇ Python 3.11 (Stable)

✅ Check "Add Python to PATH" during install!

Setup

Installation steps

1

Download and extract

Download the .zip above and extract it anywhere — e.g. C:\LXX\

2

Install dependencies

Open the extracted folder, then open a terminal there and run:

pip install customtkinter keyboard pyperclip
3

Or just double-click setup

Run setup.bat inside the folder — it installs everything automatically.

4

Launch LXX

Double-click run.bat or run:

python main.py
5

Link your account (optional)

Create an account, go to your Dashboard, copy your Auth Token, and paste it into LXX → Settings → Account. This unlocks your Premium tier if you have it.

⌨️ Hotkeys

Ctrl + Space Transform & replace what you just typed
Ctrl + Shift + Space Toggle overlay visible / hidden
Ctrl + Shift + X Toggle keyboard interceptor on / off
